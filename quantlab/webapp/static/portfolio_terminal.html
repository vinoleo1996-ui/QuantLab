平台能力说明

  1. 盘中实时行情：启用公开行情后，持仓/行情接口才会向新浪（腾讯回退）取实时价；页面仅在该模式下自动刷新。
  2. 日线数据集：每日收盘后运行 scripts/daily_pulse.py，增量补齐当日 K 线与候选池快照，因子/专家意见即基于最新数据重算。
  3. 月度信号：按运行配置评估；没有通过研究关口的信号只用于模拟。
  4. 美股：交易链路尚未启用；背景信息也必须满足历史可知时间要求。

每日一条命令

./.venv2/bin/python scripts/daily_pulse.py          # 收盘后：更新日线+候选池 → 更新专家意见
./.venv2/bin/python -m quantlab.cli quote           # 随时：查看当前持仓实时行情
./.venv2/bin/python -m quantlab.cli monitor         # 随时：重算专家今日意见
./.venv2/bin/python -m quantlab.cli web             # 启动本看板
