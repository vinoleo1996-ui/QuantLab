## 二、裁定：部分属实 / 口径需修正

- **"13.19% 不是可执行组合的收益"**：措辞成立但机制要说准。0.65 的配比算术没错，错的是输入端
  （全额 800k 的股票账 NAV 隐含 63% 暴露）。可实现性诊断（上）才是正确的量化方式，
  R 的"按 53.1% 线性缩放"只是近似。
- **"forward base ~13.5% 相差 3–4pp"**：R 用 2014–17 袖 6.95% + 2018–24 股票 9.46% 做的朴素
  分解（8.6%–9.3%）过冷——它同时惩罚了袖和股票腿，却没有计入 2019–2026 段本身。
  本仓口径：回测 13.19% / ex-2025 约 10.5% / 可实现（初判）12.1–12.5%，三档并列，不取单档。
- **"P5_K 触发路径 5.02/6.02%"**：数字属实（本仓 `results_cost1.csv`），本仓此前把这解释成
  "0 触发、规则惰性"是误读（读的是期末状态），已在接续文档更正为 CPPI 现金锁死。

## 五、一句话结论

R 的事实核查几乎全中（10/10 精确命中，含两个逐位相同的数字），它的核心指控——
**"13.19% 是全额假设下的数字，真实账户只买到约 55% 股票"** ——成立且已被本仓的回放审计
独立证实。P5_BASE 的资格取决于可实现矩阵：初判（3/16 条路径）组合年化 12.1–12.5%、
MDD −22.1～−23.1%，仍高于旧基线 ALLOC60（11.76%）但低于其自报的 14.69%。
在矩阵跑完前，任何"15%"或"13.19% 可执行"的表述都不采用。
