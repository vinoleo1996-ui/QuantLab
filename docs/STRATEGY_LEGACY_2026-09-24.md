# QuantLab 量化交易系统 —— 策略白皮书

## 0. 一句话定位
一个面向个人投资者的 **A股 + 美股 双市场、中期持仓(月度调仓)、约 25 只标的、目标年化 15-20%、最大回撤可控** 的多因子量化选股系统。第一版为**信号级**（生成买卖建议清单，人工执行）。

## 1. 投资目标与约束
| 维度 | 设定 |
| --- | --- |
| 初始资金 | 60 万人民币（A股与美股按配置比例分配；美股部分需合法换汇/券商账户，未就绪时可配置为纯 A股运行） |
| 持仓数 | A股 + 美股合计约 25 只（默认 A股 20 / 美股 5，可配置） |
| 持仓周期 | 中期：月度调仓（每月第 1 个交易日生成调仓建议） |
| 目标 | 年化收益 15%~20%，回撤控制优先（MaxDD 目标 < 15%，硬止损线 < 25%） |
| 执行方式 | 信号级：输出"买入/卖出/持有/减仓"清单 + 理由，人工在券商执行 |
| 风险等级 | 中高（权益多因子），通过目标波动率与拥挤度控制把"意外下行"压缩 |

## 2. 系统架构
```
data/input (AKShare: A股行情/财务/北向; yfinance: 美股)
   → data_core (增量缓存 parquet, 可交易掩码, 截面对齐)
   → factors/ (5 大类 × ~20 因子)
   → strategy/ (因子打分 → ICIR动态加权合成 → 拥挤度惩罚 → 候选池)
   → portfolio (目标波动率组合/LedoitWolf → 个股上限/行业约束) 
   → risk (回撤分级风控/单票止损/β约束)
   → engine (向量化回测 + 成本/滑点/掩码)
   → cli + webapp (报告与信号清单)
配置：quantlab/config.py，全部可调。
```

## 3. 因子体系（"多角色分析师" = 5 大类，吸收 TradingAgents 分层思想）
每类内部多个单因子，均做截面标准化 + 越界缩尾；方向做成一"打分越高越看好"。
| 大类 | 代表性因子 | 方向 | 数据需求（均免费可得） |
| --- | --- | --- | --- |
| 价值 Value | E/P、B/P、S/P、FCF_Yield、股息率 | 高价值>低价值 | 财务 + 行情 |
| 质量 Quality | ROE、ROA、毛利率、经营现金流/净利润、资产负债率(负) | 高质量优 | 财务报表 |
| 动量 Momentum | 12M-1M 动量、3M 动量、1M 反转(A股反转强)、RSI-偏离 | 混合(动量/反转分市场) | 行情 |
| 成长 Growth | 单季营收同比、单季净利同比、SUE 盈余惊喜 | 高成长优 | 财务 + 行情 |
| 资金/情绪 Flow | 换手率(负)、北向持股变化(A股)、20日量能趋势、拥挤度罚项 | 低拥挤优 | 行情 + 北向 |

**差异点**：动量类在 A股采用"中动量 + 短反转"组合（A股反转效应强、动量弱），美股采用"时序列动量"为主——避免照搬美股因子到 A股造成踩踏。

## 4. 核心机制（针对"避免踩踏 + 稳健"的三个创新）
### 4.1 可交易性掩码（Mask-first，来自 arXiv:2507.07107）
- 任何行情口径，凡当日涨停（无法买入）或跌停（无法卖出），该标的当日被掩码；
- 因子滚窗计算前先按掩码处理；回测中：涨停日不产生新买入，跌停日不产生卖出；
- 效果：避免把"看得见买不到"的收益算进策略（实测可避免 IC 虚高、Sharpe 虚高）。

### 4.2 拥挤度惩罚（防 2026-07 式风格共振反转）
- **个股拥挤打分**：滚动换手率分位(HI)、近 20 日涨幅与换手共振、EP 极端低+高波动；
- **因子级拥挤预警**：滚动监控同类因子收益两两相关性；相关性骤升(>0.25 长期均值阈值) → 触发降权重/降敞口；
- 组合层面：权重上限内，拥挤分位 >95% 的标的剔除；60%-95% 区间按分位线性降权。
- 参考：Quant Decoded FCI、东北证券 CNEX、西南证券动态分域、Lou-Polk(2022)。

### 4.3 ICIR 动态加权 + 市场状态贝塔
- 每个单因子滚动 60 个调仓期计算 RankIC 与 ICIR，因子合成权重 ∝ max(0, ICIR)，并对"近 12 个月 IC 显著衰减的因子"施加惩罚；
- 市场状态（基于宽基指数 20/60 日均线与已实现波动率分位）：状态差 → 目标波动率下调 / 总仓位打 7 折。把"市场怎么走"交给规则而非风格押注。

### 4.4 多专家(Multi-Expert)集成（Rd-Agent/Qlib"多 agent"思想落地）
- 类似 RD-Agent 的"多个 agent 各司其职、按验证结果融合"，把因子场景拆成 5 个专家：动量 / 价值 / 低波质量 / 流动 / 综合(全因子)；
- 每个专家用**各自因子子集**按 ICIR 动态权重+拥挤惩罚独立打分，并独立选自己的 top 池；
- 专家级置信度 = 该组因子最近 N(默认12)期 IC 均值的 softmax——近期 IC 差的专家自动降权（且不做硬清零，保多元性）；
- 最终候选 = **多专家 top 池并集**（而非把分数硬合成单排名），再走目标波动率配权。真实 A股 2020-2026 回测对比：单专家 vs 多专家 → 年化 18.7%↗23.8%，Sharpe 1.10↗1.32，最大回撤 -19.95%↘-16.17%，平均换手还从 3.6% 降到 3.2%（见 research notebook 的 A/B）。

### 4.5 最小持有期约束
- 常规再平衡（未触发硬降仓）时，建仓未满 `min_holding_period_days`(默认20交易日)的持仓不因信号变化卖出，抑制"信号抖动→买回又卖出"的磨损；仅在风控缩放(scale<1)时放行卖出。

## 5. 组合构建
- 候选池：A股=全市场剔除 ST/次新(<60 交易日)/停牌/日均成交额<3000 万/市值<60 亿；美股=SP1000 成分池。
- 打分：多专家集成（见 4.4）；最终组合从候选池按 **目标波动率 + Ledoit-Wolf 收缩协方差** 求权重，个股上限按 `1/N±Δ`（默认 ±1.5pct），行业/市场暴露受限。
- 权重调整：例行调仓仅当候选相对持仓排名变动超过阈值（默认 5 名）或新标的进入 top 23 才触发替换，加上最小持有期（4.5），**刻意压低换手**（中期风格）。
- 成本建模：A股 佣金 2.5bp(万2.5) + 卖出印花税 5bp + 冲价滑点 30bp；美股 佣金 1bp + 滑点 15bp。
- 数据链路：AKShare(东财) → Baostock(前复权全A日线) → 东财 curl_cffi → 腾讯 fqkline → 新浪快照，逐级 fallback；**所有真实后端失败即报错，离线合成链路已于 v2.4 移除，任何面板都不再出现人造数据**。

## 6. 风控（分级）
| 层级 | 规则 | 触发动作 |
| --- | --- | --- |
| L1 单票 | 单票回撤 > 16% 或评分跌出候选 top 40 | 输出"减仓/换出"意见 |
| L2 组合 | 组合回撤 > 10% | 目标波动率下调一档（14%→11%） |
| L3 组合 | 组合回撤 > 15% | 总仓位 × 0.7 |
| L4 组合 | 组合回撤 > 22% 或市场状态为深熊 | 仓位降至 ≤30%，只保留高分防御因子组合 |
| 拥挤 | 因子拥挤预警/组合两两相关 > 阈值 | 降动量+成长权重，增加质量+价值 |
以上全部生成"信号与理由"，由人工复核执行，不自动下单。
