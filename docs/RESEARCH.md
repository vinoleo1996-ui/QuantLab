## 二、2026 年以来关键研究结论（按对策略的直接影响排序）

### 1. A股涨跌停可交易性掩码（Mask-first）—— 最容易被忽略的"免费 Alpha"
来源：arXiv:2507.07107 *Machine Learning Enhanced Multi-Factor Quantitative Trading*（清华大学/开源系统 ml-quant-trading）
- 问题：A股有 ±10%（主板）/±20%（创业板/科创板）涨跌停限制。涨停日的收盘价无法买入，跌停日无法卖出。滚窗计算（均线/相关系数/排名）把这些"不可执行价格"吞进去，会造成**上游污染（upstream contamination）**。
- 量化影响：虚高 RankIC 约 +18%，实际 Sharpe 反而 -0.44。
- 对策：数据处理时先构造**可交易掩码**，所有窗口计算、排名、回测成交都带上掩码。
- 我们的落地：数据层生成 `mask (tradable=1/0)`；涨停当日该标的不得新买入，跌停当日不得卖出；回测成交价使用真实次日/开盘价并惩罚滑点。

### 2. 因子拥挤度是近两年 A股回撤的主因（必须防踩踏）
来源：
- 长江证券《复盘两轮量化回撤》——2024-02（小微盘流动性踩踏）、2026-06~07（科技抱团瓦解、动量/β/波动/流动性同步承压），两段均约一个月内回撤 20%。
- 东北证券 CNEX 因子拥挤模型(2026-09)：拥挤度分"追涨交易型/静态高估型/结构脆弱型"；行业拥挤状态中位数约 21 个交易日回落，98% 分位约 137 个交易日；拥挤度与未来 0-6 月收益负相关（未显著），与未来波动率正相关（显著）。
- 西南证券动态分域行业配置(2026-07)：行业换手集中度 RITC 进入历史 80% 分位后，情绪扩散因子 RDSI 的 IC 从 0.07 骤降到 0.01 失效；高拥挤环境用相对换手率 IRT 反而能识别"天量见天价"。
- Quant Decoded 因子拥挤指数 FCI(2026-04)：三信号（空头集中度 HHI、因子 ETF 相对资金流、因子收益两两相关），**因子相关性与 FCI 是最强单信号**，1.5σ 阈值触发降敞口；拥挤调整后动量 Sharpe 0.55→0.71、回撤 -52%→-31%。
- 湘财证券/东证期货：因子拥挤度用"多空换手率比例"度量。

→ 我们的落地：**双通道防拥挤**
  a. 个股级：滚动换手率分位、短期涨幅+换手共振（天量见天价）、财务高估（EP 过低）+高波动 → 拥挤打分，剔除/降权；
  b. 因子级：滚动监控"因子收益两两相关 + 因子 IC 衰减"，触发阈值则下调该因子权重（动态 ICIR 权重 × 拥挤罚项），并在报告中给出"拥挤预警"。

### 3. 组合构建：收缩协方差 + 目标波动率 比朴素均值方差稳健
来源：arXiv:2507.07107 实证（Ledoit-Wolf 收缩对 Sharpe +0.18，Markowitz 直接解不稳定）；DeMiguel et al. 经典结论（1/N 常比未约束 MVO 好）。
→ 落地：Ledoit-Wolf 收缩协方差 + 目标年化波动率（默认 14%）推导组合杠杆/β，个股上限权重、行业暴露约束。

### 4. 点态新思路（记录，暂不首版启用）
- **KellyBoost**（arXiv:2608.23393, 2026-08）：用负对数增长率做 XGBoost 损失，输出即组合权重。→ 列入 Roadmap 的"成长型权重引擎"。
- **Adjusted-MSE / 符号感知损失**（arXiv:2507.07107）：方向错误比幅度错误惩罚 11 倍。→ 用于后续 ML 打分模块。
- **Agentic Factor Mining**（arXiv:2603.14288/2603.16365/2608.13913）：LLM 闭环挖因子。→ 前提是需要稳定 API + 数据；用 CLI 插件位置预留，不阻塞首版。

## 三、多专家(Multi-Expert)集成落地（2026-09）
- 参照 **RD-Agent（多 agent 各司其职、按经验表现融合）** 与 **TradingAgents（分析师分层投票）**，将策略从"单一复合打分"升级为 5 专家并集：动量 / 价值 / 低波质量 / 流动 / 综合。
- 专家级置信软融合：softmax(组内因子近12期 IC 均值) ≥0；专家独立选池 → 候选并集 → 目标波动率配权（见 STRATEGY.md §4.4）。
- 真实 A股 A/B（2020–2026，40选股月度）：年化 18.7%→23.8%，Sharpe 1.10→1.32，maxDD -19.95%→-16.17%，平均换手 3.6%→3.2%（并集并未放大换手，反向收窄）。
- 同步加入"最小持有期 20 交易日"抑制抖动换手（STRATEGY.md §4.5），并验证 Baostock 前复权全A日线作为第二数据后端（含换手/涨跌/isST 字段，免 token）。

## 三、结论
- 首版策略的差异化（避免与主流指增/量化拥挤踩踏）集中在三点：
  1. **可交易性掩码**（多数开源回测不做，等于定期吃到假收益）；
  2. **拥挤度惩罚 × 动态 ICIR 权重**（把 2026 年两轮回撤写进风控）；
  3. **目标波动率组合 + 双市场**（A股权益 alpha + 美股分散）。
- 不把"重仓单一风格/单一行业"当作收益来源；风格暴露被显式约束（控制 Beta、行业上限）。
