# 预注册：P2 组合层（风险平价合成）

（2026-10-08 CST 登记。用户 10-08 批准的计划第 7 步；E4 的用法由用户 10-08 选定：主规则不用 E4，E4 版本只报告。登记前没有算过任何组合结果。登记后不可修改。）

## 要回答的问题

把二期通过门槛的腿和 M2 冻结腿按事先写死的风险平价规则合成后，60 万元账户能否达到年化不低于 15%、最大回撤不超过 25%。

## 计数

单独一族 `P2_portfolio`，1 次试验：`RP3`。T3 开关在完整组合上的复核按 `P2_M2_TILT.md` 的约定不算新试验，台账记为诊断行，但结果双向有效。

## 参与合成的腿

| 腿 | 来源 | 调仓成本（按权重变化） |
|---|---|---|
| M2 冻结腿 | `output/p1_m2_20261008/is/ledger_nav_{相位}_{种子}_cost1.csv`，10 条路径 | 0.4% |
| 可转债双低 | `output/p2_cb_double_low_20261008/nav_main.csv`（`CB_DL20` 通过本腿门槛） | 0.1% |
| C 腿（被动防守） | 中证转债指数 000832 与红利低波 H20269 各半，按日再平衡合成一条指数（000832 来自 `data/cb/index_000832.parquet`，H20269 来自 `smallcap_audit.bench_series`，与质量红利腿的基准相同） | 0.05% |

- 成本 2 倍时，M2 用 `_cost2` 净值，转债用 `nav_cost2.csv`，调仓成本也乘以 2。
- **去重口径**：C 腿作为一个整体资产参与风险平价，不与主动转债腿合并，也不拆开。两者都含转债，重叠部分由风险平价按波动率自然分配，不另做调整。
- **股票只数**：股票腿只有 M2（不超过 50 只），转债和指数不占股票只数，50 只的上限没有冲突，也就没有"从 50 只缩减到配额"的损失。
- 没有通过的腿（大中盘事件族、ETF 轮动、质量红利）不参与。

## 规则

- 每个月最后一个交易日收盘，按过去 120 个交易日日收益标准差的倒数分配权重，下一个交易日起生效；月内按持有漂移。攒够 120 个交易日之前，三条腿等权。
- **T3 开关版**：M2 的风险平价权重乘以 T3 系数（直接读取 `output/p2_m2_tilt_20261008/indicators.csv` 的 `k_T3` 列，不重新计算），上限为 1；另外两条腿按原比例分配剩余权重。
- **主规则**：T3 开关版在完整组合上通过复核（门槛同 `P2_M2_TILT.md`：相对固定权重版，年化提高至少 0.5 个百分点且回撤不变差，或回撤改善至少 3 个百分点且年化损失不超过 0.5 个百分点；10 条路径中位数、成本 1 倍），就用开关版；否则用固定权重版。
- 样本段：2018-01-02 至 2026-09-22。

## 门槛（主规则；成本 1 倍；10 条路径的中位数）

年化不低于 15%，并且最大回撤不超过 25%。

## 只报告（不竞选、不替代主规则）

- 成本 2 倍；
- 去掉 C 腿（M2 加转债双低）；
- **E4 版本**：把 M2 腿换成冻结的 E4 配置（`scripts/smallcap_e4.combine`，M2 60%、黄金 15%、十年国债 15%、纳指 10%，季度再平衡），其余不变，开关不作用于它；
- 各腿单独的年化、回撤和平均权重；各腿两两之间的月收益相关性；
- 10 条路径中同时满足年化 15% 和回撤 25% 的比例。

## 结果改变的决策

- 通过：进入前向记录（6–12 个月），前向记录才是最终裁决。
- 不通过：如实记录与目标的差距，不在组合层调参数补救；是否开新腿或调整目标，由用户决定。
- `promotion_approved=false`。
