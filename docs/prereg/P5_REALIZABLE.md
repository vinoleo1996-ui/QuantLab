# P5_REALIZABLE：整手约束下的可实现 P5_BASE（诊断，2026-10-17 22:50 CST）

## 问题

P5_G0/P5_BASE 报告的组合收益把股票腿当可细分资产：`65% × 97% = 63.05%` 股票暴露。
A 股整手 + 80 万本金下这个暴露买不到——`p5_base_orders.py` dry run 只成交 46/50 只，
股票 425,065 元 = 53.1%，现金约 12%。本诊断量化"回测组合"与"可实现组合"的差。

## 过程记录（诚实登记）

- 首个 cell（520k × cost1 × p0_s1）在本文写就前已启动，用于校准运行时间；这不是流程范例，
  后续 cell 均按本预注册的口径执行，全过程只读既有冻结数据与生产引擎，无参数搜索。
- 不替换任何既有结果；P5_G0/P5_BASE 的回测数字保持原样，本诊断只回答"能买到多少"。

## 设计（零网格搜索）

- 股票腿：生产引擎 `quantlab/p4_ledger.replay`，目标计划与 POOL50 逐位一致
  （`scores.parquet` + `random_order(seed)` + `schedule`），`capital_cny` 取真实子账规模：
  - 520,000 = 65% × 800,000（现行本金口径）；
  - 390,000 = 65% × 600,000（历史口径，仅用于可行性对照）。
- 组合：股票子账 NAV 经 `quantlab/p4_alloc.allocate` 与 G0 袖打包，65/35、季末再平衡、
  QDII 溢价暂停溢出 1:1 给黄金/十年国债、无灾难线——与 P5_BASE 逐项一致。
- 成本：股票侧 0.4%、ETF 侧 0.05%，cost 1 倍与 2 倍都跑。
- 输出：每路径 cagr/mdd/均值暴露/均值现金/均值持仓只数/退市末态；中位数与 p10–p90。
- 证据：`output/p5_realizable_20261017/`（report.json + 逐路径 NAV csv）。

## 判定门槛（对照 P5_BASE 报告值）

1. 成本 1 倍中位年化 ≥ 回测 13.19% − 1.0pp，即 ≥ 12.2%（整手损耗上限 1pp）；
2. 成本 2 倍中位年化 ≥ 12.33% − 1.0pp；
3. 中位 MDD 不差于 −23.5%（回测 −22.78% 再放宽 0.7pp 给集中度上升的尾部）；
4. 60 万口径下均值股票暴露 ≥ 48%（低于此则 60 万本金不可实现，需改 mandate 本金）。

## 已知限制

- ETF 腿在配比层不含整手取整（ETF 单手金额占比 <0.1%，影响可忽略）。
- 股票子账的回测-实现差含两部分：规模缩小（预算减半→更多现金）与 4 只高价股被剔除；
  本诊断不拆分两者，只报合计。
- 退市清算按 `settle_delistings` 的做法在并行会话实现中；本诊断的末态检查会标出持有退市股的路径。

`promotion_approved=false`。本诊断不产生新策略，只决定 P5_BASE 是否还有资格进入前向记录。
