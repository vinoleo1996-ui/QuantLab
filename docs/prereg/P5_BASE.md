## 规则

- 股票：65% 权重 × `POOL50_G97` 账本（97% 仓位）；名义股票上限 63.05%。
- 袖：35%，黄金 518880 13.125%、十年国债 511260 13.125%、纳指 513100 8.75%（3:3:2），季末再平衡。
- QDII 溢价 >3% 暂停加仓；溢出额度按 1:1 给黄金与十年国债（首版若未实现，按全额给国债并注明）。
- 灾难线：23%（65% 下 0 触发；保留作为尾部保护）。
- 成本：股票 0.4%、ETF 0.05%；成本 2 倍另跑。样本 2018-01-02 至 2026-09-22；80 万；打新 1.5% 封顶。

## 门槛（全部满足才算通过）

1. 成本 1 倍：组合年化中位数 + 打新 ≥ 13.0%；
2. 组合最大回撤中位数不差于 −25%；
3. 成本 2 倍：组合年化中位数 + 打新 ≥ 11.0%。

## 结果改变的决策

- 通过：成为实盘基线，进入纸面前向（6 个月，落后 3pp 停）。
- 不通过：回 `ALLOC60`，记录 G0/G97 组合在哪个门槛失效。
