# mandate 更正：候选排序改用 Calmar（2026-10-18 17:05 CST）

## 决定

用户 2026-10-18 拍板：候选策略不再以"8 条路径全部 ≥ −25%"作为唯一硬门，改为
**按 Calmar（年化 / |最大回撤|）排序**，由用户在候选间拍板。

## 不变的部分

- 资本 80 万、≤50 只、只做多、无杠杆、扣费后长期年化目标 15% 全部不变。
- 旧预注册里的绝对门槛**保留为历史记录**，不追溯修改、不重算已判定的试验；
  新试验必须同时报告 Calmar、CAGR/MDD、bootstrap 5% 分位 MDD、逐年、ex-2025、
  换手与成本，不只报一个比率。
- 已登记的 P5_H 仍按其自身预注册（换手 ≤2.95×、MDD ≥−36.6%）判负。

## 即时后果（如实记录）

- P5_H 19.49%/−41.4% → Calmar **0.47**，仍低于 P5_BASE 13.57%/22.08% → **0.61**；
  成本2 0.35 vs 0.56。Calmar 不会救高回撤策略。
- G0_60 名义 12.70%/19.11% → Calmar **0.66**，在上述候选中最高；作为配置候选另行预注册。
- 任何候选进入实盘仍需用户另行批准，`promotion_approved=false`。

## 禁止

不因为改排序而放宽数据/执行门槛；不把 Calmar 当作单期数字挑赢家的工具；
不追溯修改已关闭试验的判定。
