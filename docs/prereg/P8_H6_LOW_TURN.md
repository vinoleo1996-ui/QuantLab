## 与 P5_H 的关系

P5_H 已按自身预注册判负：换手 5.40× ≫ 2.95×、MDD −41.4% ≪ −36.6%，且四相位×两种子结果
逐位相同（日频触发使相位失效，八路径退化为一条）。本试验**不改变 P5_H 的判定**，
而是另立一个假设：把卖出带宽当作唯一旋钮，用**先验换算表**把它定死，再跑一次。

## 先验换算（写死，不看收益）

- 20 日检查 + entry 0.10/exit 0.50：年单边换手 **2.9472×**（P4_LOWTURN 实测）。
- 每日检查 + entry 0.10/exit 0.50：年单边换手 **5.4036×**（P5_H 实测）。
- 假设换手近似与 (1 − exit_frac) 成正比：k_daily = 5.4036 / 0.50 = 10.8072；
  要 ≤2.95 → (1 − e) ≤ 2.95 / 10.8072 = 0.2729 → e ≥ 0.7271。
- **取 exit_frac = 0.75**（向上取整到 0.05），entry_frac 固定 0.10，不搜索、不看结果调。

## 规则（其余与 P5_H 相同）

- 池：ADV 后 40% 带（`pool_on` 相对带，history≥253、ADV≥5m、剔 ST、剔 BJ），50 只、
  97% gross、行业上限 12、等权、日频检查。
- 每日收盘后：跌出池内分数前 75% → 次日开盘卖；空位只从池内前 10% 按分数补。
- 事件否决：ST 在信号日剔除（panel `is_st`）；退市由账本结算；
  业绩预减/减持公告本地无 PIT 源 → **不否决**，如实记录。
- 分数：`output/p4_alpha_20261012/scores.parquet` 的 GBDT，每 5 个 session 更新一次，
  两次之间用最近一期；tie-break (code, seed)。
