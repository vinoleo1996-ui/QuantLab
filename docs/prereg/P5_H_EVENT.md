# 预注册：P5_H 事件驱动持仓（每日触发，无固定调仓日）

（2026-10-17 CST 登记。登记后不可修改；更正只追加在文末。）

## 动机

- 现行 `POOL50` / `AMIHUD20` 是每 20 个交易日按日历换仓的随机 50 只，**这是研究对照，不是可上实盘的交易规则**。用户明确拒绝"到点买入卖出"。
- 方案甲（`GBDT_HYST`）已经证明"持有到跌出前 50% 才卖、只从前 10% 补"能把年单边换手从 6.7x 压到 2.95x，并多 +2.27pp（t=0.95）。它仍是 20 日检查；每日触发是它没测过的那一半。

## 规则（与 `POOL50_G97` 相同的部分）

- 池：`AMIHUD20`（若 P5_G 通过）或 `POOL50`（若 P5_G 不通过）。
- 股票：50 只、97% 仓位、等权、每申万一级行业最多 12 只。
- 分数：`scores.parquet` 的 GBDT 分数，每 5 个交易日更新一次；两次更新之间用最近一期。
- 成本：成本 1 倍与 2 倍各跑；80 万；样本 2018-01-02 至 2026-09-22。

## 唯一改动：把"每 20 日调仓"换成"每日检查 + 触发"

每个交易日收盘后：

1. **卖出**：持仓在池内的分数分位跌出前 50% → 次日开盘卖；或触发事件否决（ST、退市整理、业绩预减、减持公告）→ 次日开盘卖。
2. **买入**：空出的位置只从池内前 10% 的股票里按分数从高到低补，受行业上限约束，补满 50 只。
3. **不设固定调仓日**：没有触发就不交易；持仓权重只在买卖发生时调整，其余时间按市值漂移。

## 门槛（全部满足才算通过）

1. 成本 1 倍：账本年化中位数 ≥ 13.86%（对照 `POOL50_G97` +1pp）；
2. 成本 2 倍：中位数 ≥ 12.59%；
3. 年单边换手 ≤ 2.95x（不高于方案甲）；
4. 最大回撤中位数不差于 −36.6%。

## 结果改变的决策

- 通过：成为实盘候选（事件驱动版），替换日历版进入配比层；另登记配比试验。
- 不通过：日历版只作研究对照，实盘继续等新的触发规则；不调阈值救结果。
