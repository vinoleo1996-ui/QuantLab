# S1 零成本归因结论（2026-10-18，验证方案 v2 之 Layer S1）

性质：诊断，非试验（trial 计数不变）。入口 `scripts/attribution_s1.py`，证据
`output/attribution_s1_20261018/report.json` + `path_*.csv` + 运行日志
`output/attribution_s1_20261018_run.log`。方法：非重叠 20 格日开盘到开盘等权、
不计成本，可交易资格与 `scripts/p5_g_amihud.py:41-43` 一致（历史≥252、ADV≥500 万、
剔 ST、剔北交所）；开盘价按 `quantlab/alpha/labels.py:15-17` 复权。

## 结论一句一条

**C1（S1.1，判定独立于口径差异）：ADV 后 10% 不是新池。**
它与现行 ADV 后 40% 带的逐期重叠中位数 = **1.0**（按构造是当前池的真子集），
与 Amihud20 的重叠 = **0.91**、20 期收益相关 = **0.99**。"换 ADV 后 10% 就能多赚"
若是真机制，现行账本早已吃到；把子集单独拎出来重开没有任何增量信息。
**决定：kill——ADV 后 10% 不进 S3，不配 3.5 小时账户工时。**

**C2（S1.2）：Amihud20 的池级超额经不起波动率倾斜回归。**
对波动率暴露（池 |日收益| 均值 − 可交易全名单同值）回归后，截距 NW t = **0.91**
（<2.0），斜率为正。结合 P5_G 账户证据（MDD −36.9 全破线），"非流动性溢价"
在池级也不显著、在账户级为负。整个 illiquidity/低成交尾段切法族（含 Amihud
前 10/20/30%、ADV 后 10/20/30% 变体）**永久关闭，不再重开**。

**C3（S1.3）：换手率排序进带同样死亡。**
按 20 日平均换手率取后 40% 的池（ADV 仅作容量下限），池级年化 **−7.1%**，
远低于现行带的 +2.6%（本口径）。用户方向上提出的"换技术面定池"，实测两条
（Amihud、换手率）都不如现行。**kill。**

**C4（对幽灵扫描的裁定）：2026-10-17 宇宙扫描的 22.74%/21.89% 不可复现，
且不可复现的部分恰好是脏名字。** 无资格下限的 amihud20 变体在本口径只有
**+7.0%**，加回 ADV≥500 万+剔 ST 后降到 **+3.8%**——即那批高收益主要由
不可交易的 ST/极微盘贡献。扫描脚本从未提交入仓（全仓 grep 无源），其数字
不满足"每个实验引用可核验源码身份"的要求。**裁定：宇宙扫描结论降级为
不可采信证据；今后任何池级数字必须附可重放脚本才允许立项。**

**已知口径差（诚实披露）**：本复现的 adv40low=+2.6% 与台账"池子等权 16.25%"
差距大，差异未完全归因（候选：扫描持有期初名单到期末 vs 每格日重画、
资格过滤顺序、样本网格起点）。这不改变结论——C1/C2/C3 的比较全部在同一
口径内成对完成，且 C4 用同口径的有无下限对照。若需要，另行预注册重放
leak.json 的 16.25% 口径（它才是与账本同源的锚）。
