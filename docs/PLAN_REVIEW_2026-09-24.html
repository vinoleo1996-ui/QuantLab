二、方案的问题

结构性 2.1 缺少最便宜的证伪实验，把"证伪"和"重建"打包进了一个五阶段路线图

方案的第一阶段是 ~25 个工程条目（账本、数据契约、PIT 池、公司行动、ETF 规则、指数独立接口…），第二阶段是新因子模块、公告模块、防踩踏、新配权。全部做完是数人月的规模。

但在投入之前，有一个问题必须先有答案，而且它只需要几天：

在 40 只大盘股的池子里，用 20 个交易日的横截面价量信号，
扣掉单边 30bp 滑点 + 双边佣金 + 印花税之后，
还剩多少可提取的 alpha？

已知的强证据是：该池子的被动收益是 28–33%/年，而"策略"只有 14.6%（相对同池月度等权年化 −10.76%，相对买入持有 −13.57%）。方案自己也承认"当前结果不能用来判断动量、价值或专家集成是否有效"——那么下一步就不该是"重建一整套系统去度量它"，而该是先构造一个能一次判死的对照。

缺的对照（方案里完全没有）：匹配的随机打分零假设。把打分层替换为随机截面分数、下游整条管线逐位不动，跑 ≥500 个种子，得到年化/回撤/换手/未成交的分布，再看修复索引后的策略落在哪个位置。构造与判读见 §4.2 与 §4.3。

能得到的结论只有一条：这套排序机制相对随机选择有没有可检测的增量。

  • 不可区分 → 停止在这段数据上继续调这套机制；措辞是"未证明优于随机选择"，不是"池内没有可提取收益"，也推不出"换池会更好"。
  • 显著超出 → 支持"该池条件下存在选股增量"，但结论仍以有偏池为条件，幸存者偏差未解决。

我上一轮已经证明池宽 ±1 只就让人工年化从 13.55% 摆到 16.00%——这个零假设分布大概率很宽，所以必须先测它，否则"修复后的 12.88%"会被误读成"策略 alpha 接近 13%"。（本报告初稿在这里写过"测不出就该换池子"，已在 §4.0 撤回。）

叠加"每代最多评估 12 组配置"，多重检验校正在 5 个窗口上几乎没有分辨力。方案已经很诚实地写了"证据不足时维持'未证明有效'"，但应该再往前一步：明确写出"以 6 年日线数据，本设计大概率无法把真实增量与噪声区分开"，并把结论的默认值设为"未证明有效"而不是"待验证"。

正确做法不是放宽门槛，而是：把数据切成更细的滚动窗（提高窗数）、或改用日频标签（提高每窗观测数）、或接受"无法在历史数据上判定"并把唯一验证路径放到前向模拟。

四、最小证伪切片（含对本报告上一版的撤回）

撤回 4.0 我上一版的判据写错了

本报告初稿在这里写的是：

若策略年化落在随机篮子分布的 90% 分位以内:
    -> 该池内无可提取的横截面 alpha
    -> 下一步是「换池子」，不是「换因子」

这个推论不成立，撤回。三处错误：

  • 把"没测出差异"当成"差异不存在"。无法拒绝零假设 ≠ 接受零假设。它只能说明这套排序机制相对随机选择没有可检测的增量，推不出"池里没有可提取的收益优势"——池里可能有用别的规则能提出来、而这套规则提不出来的结构。
  • "所以该换池子"是无根据的跳跃。换池是一个独立的、需要自己证据的假设，不是前一个检验的推论。更宽的池子同时带来更多噪声、更多多重检验、更差的流动性和更高的滑点，不是免费的。
  • 零假设没有被指定。"随机篮子"是个含糊说法。若不匹配持仓数、资金、费用、风控和可交易条件，测出来的差异里混着配权机制、风险叠加和执行假设，无法归因到"选股"。

两个结构性限制必须写在实验报告里：

  • 条件性。零假设以"今日快照 TOP40"这个池为条件。它检验的是选股机制，不是池子的机会集。即使策略显著胜出，结论也仍被幸存者偏差污染。
  • 单侧。这是单侧检验。不显著只是"没有证据支持继续投入这套机制"，不是"证明机制无效"。

4.2 匹配的零假设怎么构造（正好满足你提的匹配要求）

不要"随机抽 27 只再自己配权"——那样差异里混进了配权机制。正确做法是只随机化打分层，其余整条管线逐位不动：

把 composite_score 的输出替换为 i.i.d. 随机截面分数（每个种子一套）
其余全部保持不变：
  候选截取 + buffer 规则 -> 最小方差配权 -> 目标波动率缩放
  -> 回撤分级叠加 -> 涨跌停/停牌掩码 -> 双边成本 -> T+1 开盘执行

这样持仓数、资金、费用、风险控制、可交易条件全部自动匹配，因为下游一行代码都没变。已知的对照：把分数换成常数0.5 时逐日收益差恰好为 0——随机分数版就是这个消融的"有分布"版本。

注意两点：回撤叠加是路径依赖的，每个种子必须走自己的风控路径，不能共用一条；持仓只数会因掩码与止损而逐期波动，这一点也由构造自动匹配。

但"完全匹配"做不到，必须写明残余差异：整手约束、最低佣金、真实成交价在现有引擎里根本不存在（min_trade_value、cost_rounding 是死配置，见 §2.2）。在账本补齐之前，这个零假设只能在"权重空间"上匹配，不能在"成交空间"上匹配。所以它给出的结论强度，上限就是当前引擎的保真度。

4.3 阈值怎么读（不要设 90% 硬门）

  • 报告 p̂ = 年化 ≥ 策略的种子占比，而不是"过/不过 90%"。在 p̂≈0.1 时，200 个种子的抽样误差约 ±2pp——把 0.10 当悬崖是错的。要分辨 p < 0.05 需要 ≥500–1000 个种子。
  • 2020–2026 已被反复查看（两位同事 + 我自己都在上面跑过对照），门槛必须按查看次数上浮，不能直接拿 90 分位当显著性线。
  • 单点结论不可用：同时报告年化、回撤、换手、未成交四个维度的分布位置。策略可能年化落在中位、但回撤落在 20 分位——那是"低波 beta"，不是 alpha。

4.4 什么才真正支持"换池子"（独立论据，不是上面的推论）

我上一版想表达但写错的直觉，正确的版本是一个仪器分辨率问题，与"别处有没有 alpha"无关：
