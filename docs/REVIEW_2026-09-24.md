## 2. 按严重程度排序的核心问题

### F01 · P0：因子权重整行丢失，专家排名失效

位置：[engine.py:184](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:184)、[scoring.py:117](/Users/agiuser/Desktop/QuantLab/quantlab/strategy/scoring.py:117)、[monitor.py:107](/Users/agiuser/Desktop/QuantLab/quantlab/strategy/monitor.py:107)。

```python
w_row = w_fac.to_frame("w").T.reindex([t])
```

转置后行索引为字符串 `"w"`；`reindex([t])` 是按照时间戳取新行，并非修改原行名称。因此全部因子权重变成 NaN。`composite_score` 再把这些权重填成 0。

- 当前最后一期：11 个因子权重全部缺失；40 只股票的专家总分全部等于 **0.5125**。
- 五个专家的候选列表只有 **1 种**；现有 `monitor.json` 中五份 Top20 完全相同。
- 仅在取证内存中用 `pd.DataFrame([w_fac.to_dict()], index=[t])` 修正索引，恢复 **40 种分数和 5 份不同的专家名单**。
- 把输入因子整体翻转符号，当前打分完全不变。

**后果：ICIR、专家置信权重、因子拥挤惩罚虽被计算和展示，却不能传导到股票排名。当前选股主要受同分时的排序规则影响；同分排序没有稳定性保证，可能随库版本、列顺序变化。** 波动率优化、止损和市场状态仍在工作，所以净值可以看起来合理。

修复后的验收必须同时覆盖 engine 和 monitor：异质因子产生异质分数；翻转强因子能改变相应排序；权重不得全空；不同专家必须能在构造样例中给出不同偏好。仅断言净值有限不能发现此问题。

### F02 · P1：旧仓离开候选池后绕过禁卖，交易费用同时漏算

位置：[engine.py:247](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:247)、[engine.py:251](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:251)、[engine.py:280](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:280)。

`w_exec` 只含本期目标股票，禁卖检查只遍历这个集合。旧仓被完全剔除时，不进入禁卖、最短持有或止损循环，最后 `w_now = w_exec` 直接把它丢弃。

费用使用 `(w_exec - w_now).abs().sum()/2`。pandas 对股票索引自动对齐，新增和移除标的会产生 NaN，求和时被跳过。确定性样例中，3 只旧股完全换成另外 3 只，新旧权重均为满仓等权：

| 应检查的事项 | 当前代码结果 |
|---|---|
| 全组合换仓的单边换手应约为 100% | 记录为 **0%** |
| 如这些变化确实成交，按现参数费用应为净值的 0.70% | 记录为 **0** |
| 旧股开盘跌停，原权重 1/3 | 新组合中直接消失 |

这里 0.70% 是对记录中全部权重变化的费用核算；真实撮合首先应拒绝跌停卖出，不能先假设全量成交。

当前存档的组合集合变化较少，单独修正费用在受控重放中影响很小；修好 F01 后股票开始真正轮换，此漏洞的影响可能显著放大。初次只有买入时，现有对称费率还多算半份印花税，费用误差方向并非恒定。

应先建立“旧仓 ∪ 目标仓”的完整订单集合，再按方向检查可交易性、现金与费用，只有真实成交才能变更持仓。

### F03 · P1：止损覆盖跌停禁卖；卖不掉仍可买入超额仓位

位置：[engine.py:257](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:257)、[engine.py:270](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:270)、[engine.py:247](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:247)。

执行顺序先保留跌停旧仓，再由 L1 把权重改成 0，之后没有重新检查可卖性。样例中个股自建仓已跌 20%，下一个执行日又跌停，仍被成功清仓。

另一处在冻结卖出后保留旧权重，却不削减原定新买单。样例中最终总权重为 **123.33%**，隐含现金 **-23.33%**。没有现金账户、可用资金或成交后的总仓位检查。

对现有存档逐期核查，没有发现记录中的被禁卖减仓违例，存档最高总仓位为 100%。因此以上是**已复现的执行引擎缺陷，尚不能说它们已为这份存档贡献了虚假收益**。

还存在最短持有期覆盖止损、成本用建仓日收盘而非成交开盘、`.days` 使用自然日却声明交易日的问题。紧急卖出意图也必须服从可交易性；失败订单应延后，并保留风险敞口。

### F04 · P1：月内固定权重，相当于每天免费调回目标仓位

位置：[engine.py:294](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:294)、[engine.py:303](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:303)、[engine.py:312](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:312)。

注释写“持仓随市场漂移”，循环却每天用同一个 `w_exec` 点乘日收益，`w_now` 月末也没有按持仓市值更新。这个公式对应每天保持固定权重，实际需要交易，但没有记入交易或费用。

反例：3 只等权股，2 只价格不变，1 只从 10→11→10，期间不调仓。买入并持有的总收益应为 **0%**，代码得到 **+0.2020%**，来自隐含的再平衡。

调仓日另把老仓隔夜收益和新仓日内收益直接相加，且用旧目标权重处理隔夜收益。若新权重按开盘权益定义，需对开盘权益重新定价，并处理收益的复合关系与真实费用，简单相加通常不等价。

这类错误的方向依赖行情：震荡时可能制造再平衡收益，趋势时也可能压低收益。冻结存档目标、取消末日交易、改用现金与调整价格单位记账的诊断结果为约 **15.50%**，高于存档值；该诊断继承了旧订单，不是完整修复后的策略回测。

### F05 · P1：缺失行情后的复牌涨跌可能整段丢失

位置：[engine.py:92](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:92)、[engine.py:304](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:304)、[portfolio.py:21](/Users/agiuser/Desktop/QuantLab/quantlab/strategy/portfolio.py:21)。

当前 pandas 3 下，`close.pct_change()` 不自动填补缺口。缺行情日以及缺口后第一天的收益都是 NaN，又被当成 0。持仓若从价格 10、缺一根 K 线、恢复时价格 8，实际三分之一仓位应损失 **6.6667%**，当前引擎记录 **0%**。

相同缺失值也被当 0 输入协方差，可能低估风险并提高目标仓位。旧 pandas 的默认行为还不同，依赖只写最低版本进一步削弱复现能力。

当前存档有 15 条“执行日仍持有但缓存当日开盘/收盘缺失”的持仓记录，多数集中在 2026-09-24；这不全等同于错误买入，但说明估值和可交易日期没有统一。缺行情时应区分停牌、源故障、未上市与退市；估值可按明确规则延续，恢复报价必须计入累计变动，禁止把未观测风险变成确定的零收益。

### F06 · P1：末日收盘信号被放回同日开盘执行

位置：[engine.py:115](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:115)、[engine.py:161](/Users/agiuser/Desktop/QuantLab/quantlab/backtest/engine.py:161)。

取样本内每月最后一行，将尚未完成月份的末行也当成月末；没有未来交易日时，执行日期直接回退为 `all_dates[-1]`。

存档最后一笔 `signal_date == exec_date == 2026-09-24`，这意味着先知道当天收盘、成交额和因子，再按当天开盘成交。同时最后一天的原持仓收益被新的分段覆盖。每次用不同截止日运行都可能改写那个截止日的历史。

应使用交易所日历识别实际月末；未完成月份的临时信号独立输出；没有下一有效执行日的订单只能待执行，不能计入净值。对任意历史截止日，追加未来数据不应改变截止日前已经执行的订单和收益。

单独取消末日交易，本次受控样本年化反而从 14.6178% 升至 14.6306%。这是确认时序错误的证据，不支持“全部高收益都来自最后一天”的说法。

## 4. 算法本身的判断

### 4.1 当前利润的解释应先回到持有资产

主模型实际是量价横截面评分、低波动组合、月度择时及止损。所谓“价值”是长短期价格反转，“低波质量”使用波动与拥挤，成长与真实财务质量并未进入主回测。名称可以帮助组织代码，却不能据此证明存在价值/质量/成长三种独立经济收益来源。

F01 使当前横截面因子选择失效，剩下的是：**今日大市值股票池 → 同分顺序截取一组股票 → 协方差配权 → 风控与止损 → 有缺陷的收益记账**。应优先解释这套实际运行机制。

按原代码的逐日损益贡献×前日净值归因，再扣除费用，可精确对回存档总盈利。累计贡献最高的前六只为：

| 股票 | 对初始资金的累计盈利贡献 |
|---|---:|
| 688012 | +11.88 个百分点 |
| 002371 | +10.77 个百分点 |
| 601857 | +9.74 个百分点 |
| 603993 | +8.91 个百分点 |
| 601288 | +7.96 个百分点 |
| 601988 | +7.65 个百分点 |

这些是**存档计算的损益来源**，不是经过约束验证的可成交贡献，也不是因子 Alpha。名单提示收益同时暴露于半导体设备、资源和银行等资产走势，需要与同池被动组合及正确宽基进行对照。

| 年份 | 存档当年收益 |
|---|---:|
| 2020，起始部分年度 | +2.12% |
| 2021 | +2.91% |
| 2022 | -9.73% |
| 2023 | +27.72% |
| 2024 | +37.30% |
| 2025 | +29.29% |
| 2026，至9月24日 | +5.22% |

平均年化主要由 2023–2025 贡献，不能解释为每年稳定赚 15%–20%。存档回撤 -16.52% 本身也没有达到白皮书 MaxDD<15% 的目标。

### 4.2 修好索引后，专家框架仍有研究上的弱点

- 五专家共享一套价格与成交数据，composite 又重复包含前四组；不能把“五个名字”当成五份独立证据。
- 专家质量取组内单因子 IC 的平均值，未评价该专家实际合成分数或实际投资组合的预测力、换手和净收益。因子 IC 的均值不等于合成信号的 IC。
- 负专家 IC 被截到0，多组负分可能再次近似等权；自适应温度会放大小样本均值差异，softmax 权重不是成功概率，界面“置信度”容易误导。
- 因子拥挤惩罚输入的是 IC 时间序列的相关，而不是可交易因子组合收益、持仓重叠、成交拥挤或流动性压力。相反方向因子还会抵消平均相关，掩盖高绝对相关。
- `adaptive_weight` 在 floor 附近有不连续性：低于阈值给0.1，略高于阈值反而接近0。阈值附近更好的因子可能获得更低权重。
- 动量与反转因子存在高度相关和对冲；`value_lowtension` 的公式在近期成交额放大时反而提高分数，与“低关注”解释相反。
- “12M-1M”注释指 `[t-250,t-21]`，实现为 `[t-271,t-21]`；这是更长、滞后一个月的动量，需先定义策略意图再统一命名和窗口。
- 因子多数窗口直接写死，不读取 `FactorConfig`；expert 使用全局 CONFIG，局部 Engine(cfg) 并不能控制全部实验。参数实验应先检查参数是否真正改变行为。

这些问题应在正确账户、数据时点与成本模型之上用消融实验回答，不能继续只比较同一历史区间优化后的最终年化。

### 4.3 目标波动率与交易可行性

Ledoit-Wolf + 不加杠杆的目标波动缩放可以作为合理基线，但预测波动不是最大回撤承诺。优化器没有因子预期收益输入，得分主要决定入池；池内决定权在历史协方差和上限约束。

缺失收益填0、仅40只股票、局部行业缺失、IPO历史长度不一，都会使风险估计偏离真实风险。若高价股票的一手金额超过计划仓位，连续权重结果也不能直接转成人工订单。应做现金、整手、最低佣金、历史印花税、交易日与停牌/涨跌停的逐笔模拟。

关于复权：不能把“前复权”本身直接等同于未来收益泄漏。若只发生正比例缩放，收益率、动量和波动指标可以保持不变。真正需要核对的是复权因子时点与一致性、原始执行价格、公司行动和现金股息、价格平均基准以及复权价与实时价混算。仅将 qfq 改为 hfq 不能验证策略因果性。

## 6. 建议的修复顺序与通过标准

1. **先修评分和明确策略定义。** 修 engine/monitor 的索引；确认有效因子、窗口、市场差异；统一时点评分入口，剔除与实现不符的“质量/成长/置信度”结论。通过分数非退化、输入扰动、代码重命名不改变经济选择等性质测试。
2. **建立逐日现金与持仓账户。** 用持仓股数/单位、现金、成交、费用、成本与公司行动生成净值；信号只产生订单。旧仓/目标仓并集检查；卖出成功才能释放资金；停牌/跌停不凭空成交；无信号日仍估值。
3. **统一时间与数据合同。** 正确资产类型和交易日历；收盘决策、次日可执行；完整/临时日线分离；数据源、复权、字段单位、新鲜度、缺口、历史上市资格均有校验。末日订单不得回填。
4. **修风险与约束。** 每日更新真实账户峰值；止损与最短持有明确优先级；所有拟成交后约束重新验证；行业无解可持现金，不能静默违约；保存求解诊断。
5. **重建研究证据。** 同期历史股票池和退市覆盖；训练/验证/最终样本外分离；保留模型选择次数；跨市场时区、币种、成本分别处理；在同一成本与交易约束下比较现金、宽基、同池等权、低波、单专家和多专家。
6. **最后重新评估年化。** 保存配置、代码/数据hash、依赖、基准、信号时间、订单与成交账本、失败原因、日度暴露。要求账户守恒、无负现金、无不合法成交、前缀一致性、缺口恢复损益等测试通过，再讨论净超额收益、回撤、容量与稳健性。

当前无需继续调 IC 窗口或温度去追更高年化；优先完成前四项，才能让下一次比较真正对应一个可执行策略。
