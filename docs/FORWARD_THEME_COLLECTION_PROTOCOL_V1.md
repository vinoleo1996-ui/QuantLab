# `theme_carrier_forward_collection_v1` 前向采集协议

状态：2026-09-29 20:20 CST 预注册；尚未形成有效决策日样本。该协议只启动研究侧
采集，不登记账户实验、不修改冻结路由器、不产生订单，也不改变
`promotion_approved=false`。

## 要回答的问题

从本协议生效之后开始，能否在固定的收盘后时点，以可复核的原始行情和题材映射，完整计算
`theme_carrier_minimal_v1`？这是**采集链路问题**，不是收益假设或账户回测。通过只允许把状态
从 `collecting` 改为“D2 完整归档后可准备原子 A/B 的预注册”；它不授权 A/B，更不授权交易。

首个被接入的外部机制仅来自 easy-stock 所启发的题材承接：昨日涨停溢价、炸板率（反向）、
题材相对强弱、上涨广度四项等权。TradingAgents、QuantMind 与 MiroFish 仍分别处于文本账本、
L2 试用验收、K=8 覆盖率之后的门槛，不能搭车进入本轮。

## 固定边界

- 池子固定为 U0：`3000 < adv_60_rank <= 5000`、`adv_60 >= 5,000,000 CNY`、此前至少
  252 个交易日价格历史；排名先于门槛，严格每 20 个交易日一次。U1 和 U_broad 不在本轮。
- 仅接收完整可排名截面。60 日 ADV、253 个价格观察、涨跌停价/价格档位、前一日与当日 bar、
  主题映射、交易日历任一缺失即整期弃权；不得以局部股票、旧本地面板、缓存或补选代替。
- 所有原始分页和映射响应须由 `ResearchSignalLedger` 保存原始 bytes、内容哈希、来源身份、
  `published_at`、`first_captured_at`、`available_at` 与实际入账时点。来源切换、自动回退或
  重转载均是新版本，不可补洞。
- `quantlab/data/realtime.py`、`quantlab/data/eastmoney.py` 的展示型解析结果不能直接作为本协议
  输入。当前独立采集器只接受调用方传入的原始响应；已注册的 `eastmoney.push2.clist` 仅是原始
  全市场分页的捕获配置，尚不是通过验收的完整 U0/主题数据提供方。

## 每个应采集日的时序

1. **持续留证，不设 18:00 停机线。** 固定来源、固定参数的每个原始页或 `fetch_error` 都要记录；
   不切换到新浪、腾讯或本地缓存，也不因晚到而丢弃原始材料。
2. 15:30--17:50：这是本 session 收盘截面原始页可申请进入同日 `decision_at` 的**捕获资格窗**。
   17:55 只是验证进度的运维预警目标，不是硬截止；若全套页均已在 17:50 前捕获，页总数、去重、
   字段映射、原始回执和行级哈希在 18:00 前完成，仍可生成该次 U0。首个有效运行须在原始清单中
   固定交易日历和 20-session 锚点，失败日期不能顺延。
3. 18:00 Asia/Shanghai：冻结这一次 `decision_at` 的资格集。只有原始内容、来源可用时点、首次
   抓取时点、验证与回执实际写入时点均不晚于截点的完整截面，才可成为本次 observation；随后
   才可能在下一交易日开盘模拟成交。
4. 题材映射、公告与文本没有 17:50 捕获资格窗；它们只按各自的原始 `available_at`、验证/写入时点
   以及本次 `decision_at` 判断。18:00 后继续采集、留证和记录失败。对某次决策晚到、晚验证或晚写入
   的材料必须写成带真实时点的回执及 `not_eligible_for_decision_at` abstention；它们不得改变已冻结
   决策，但可在下一次明确的资格检查中按真实 `available_at` 参加。无论何时都不得调用账户、目标
   生成、下单或风险执行。

`quantlab/forward_market_capture.py` 是唯一允许的首轮采集侧车：它保存原始分页，构造或接收
receipt-backed pool input，声明 U0 scope，记录 stock-to-primary-theme 映射，并写入一个全 scope
的四分量 observation 或 abstention。它不导入账户、路由、持仓或订单模块。

## 失败关闭与覆盖门槛

某一应采集日只要出现对**该次 18:00 决策**晚到/晚验证/晚写入、缺页、重复股票、非 `ok` 的 bar
质量、缺失涨停价、题材歧义、receipt/hash 不一致、U0 不完整或任一四分量不可得，即为该决策
`abstain`，基准新入场排序不得改变。这不是零分，也不是用晚到材料回填该次截面；晚到原始材料
仍是必须保留的后续证据。

覆盖分为两个互不替代的门槛：

1. **采集链路合格**：连续 3 个应采集日，哈希链校验、完整 U0 构造、原始页和行级证据均成功。
   合法市场条件导致的题材端点弃权可以保留；来源、时间、页完整性或映射失败会重置计数。
2. **端点可登记**：在采集链路合格记录上，累计 3 个完整
   `theme_carrier_minimal_v1=ok` 日期。四个成分仍只作诊断，绝不按历史单项挑选。

两个门槛都不说明信号有收益，也不允许账户。D2 的 `archived_decided` 只能在其完整十格矩阵已
归档后，作为未来原子 U0 A/B 的登记证据；后续账户仍需用户单独授权、同池/费用/持仓/风险/
保留/节奏不变，并且只替换新入场排序。
