## 1. 先把问题写成可优化的形式

### 1.1 目标不是"最大化收益"，是"在回撤约束下最大化复利"

```
max   E[ net CAGR ]
s.t.  P( MaxDD > 25% ) ≤ 5%
      N ≤ 23,  w_i ≥ 0,  Σ w_i ≤ 1 - cash_buffer
      单票 ≤ 6%,  行业 ≤ 25%,  簇 ≤ 30%
```

这是**路径依赖 + 机会约束**问题，不是收益最大化问题。约束是硬的，所以真正的控制变量是**暴露与风险**，不是信号强度。

### 1.2 收益必须分解，否则一切比较无效

```
R_p = Σ_k β_k · F_k + α + ε
F = [ 市场, 规模(size), 流动性(liquidity), 波动(vol), 价值(value), 动量(momentum) ]
```

在 `BR ≤ 23`、单因子 `IC ≈ 0.10` 时：

```
IR = IC × √BR = 0.10 × √23 = 0.48
年化超额 ≈ IR × TE
```

- TE 10% → 超额 ≈ 4.8%
- TE 18% → 超额 ≈ 8.6%
- 想拿 15% 年化，缺的 6–10pp **只能来自 β 项**（规模/流动性/市场）

**结论：在只做多 + 20 只的约束下，这是一个"用 β 拿收益、用风控守回撤、用 α 做微调"的问题。继续在 α 层投入，边际收益接近零——你自己的实验已经三次证明了。**

## 2. 必补模块（按优先级，含公式与落点）

### P0-1 多因子风险模型 + 暴露归因

**问题（可验证）**：`report/metrics.py:49 beta_alpha()` 与 `performance_table()` 只对 `config.benchmark_a="000300"` 做单变量回归。你的股票池是 `a_min_mktcap_yi=60`、`a_min_avg_amount_wan=3000`，交易带是成交额名次 3001–5000。HS300 是市值最大的 300 只——**两者几乎不重叠**。单回归的残差里装着 size 与 liquidity 的全部暴露，却被命名为 `alpha_ann`。

**做法**：
1. 用自有面板构建 6 个因子收益序列（日频）：
   - `市场`：池内市值加权收益
   - `规模`：小市值组 − 大市值组（按流通市值三分位）
   - `流动性`：低成交额组 − 高成交额组（按 20 日均额三分位）
   - `波动`：低波组 − 高波组（60 日已实现波动）
   - `价值`：高 EP/BP − 低 EP/BP（财务可用前用价量代理，须标注）
   - `动量`：12M-1M 高 − 低
2. 逐日截面回归 `r_i = β_i' F + ε_i`（WLS，权重用 sqrt(市值) 或等权），得到组合暴露 `β_p = Σ w_i β_i`
3. 归因：`R_p = β_p' F + α_p`，用已有 `newey_west()`（lags=20）给 α 的 t 值

**落点**：新增 `quantlab/risk/factor_model.py`；在 `report/attribution.py` 增加 `factor_attribution(run, factor_returns)`。

**判据（预注册）**：若 `α` 的 Newey-West t < 2.0，则"选股无 alpha"结论成立，**并停止在信号层的进一步投入**，把预算转到风险层。若 t > 2.0，说明之前的单基准口径掩盖了真实 alpha，需要重新评估。

### P0-3 回撤阶梯 → 波动率目标 + 预承诺再风险规则（消除恢复陷阱）

**问题（算术可证）**：`strategy/risk.py:98`
```python
self.gross_scale = (1.0, 1.0, 0.60, 0.30, 0.0)[self.level]
```
对应 `drawdown_alert/reduce/exit/halt = 0.10/0.15/0.18/0.20`。

| 回撤 | level | 剩余仓位 | 回本所需 NAV 涨幅 | **账面必须涨** |
|---|---|---|---|---|
| −10% | 1 | 100% | +11.1% | +11.1% |
| −15% | 2 | 60% | +17.6% | **+29.4%** |
| −18% | 3 | 30% | +22.0% | **+73.2%** |
| −20% | 4 | 0% | +25.0% | **∞（冻结，需人工审批）** |

**这就是恢复陷阱**：减仓在降低后续波动的同时，把"回本"变成了需要账面暴涨的事件。叠加恢复迟滞（需连续 5 个交易日低于 `阈值 − 3pp` 才升一级），深回撤后账户会长时间趴在低仓位。

**关键推论**：你们报告的最大回撤是 −21.3% / −22.5% / −30% / −32% 量级——**说明阶梯的第 3、4 级被真实触发过**。所以低 CAGR 很可能主要来自风控层锁死，而不是模型没有 alpha。这是一个**可以直接 A/B 证伪的假设**，成本极低。

**做法**：
1. **保留** −20% 硬停作为灾难保护（人工审批解锁），不动。
2. **删除或弱化** 15%/18% 的中间降档。替代方案：把"回撤触发"改成"**波动率触发**"——用已实现波动率的分位（`Regime` 已有 `regime_vol_quantile=0.80`）决定 gross，而不是用累计回撤。
3. 引入**预承诺再风险规则**（对称、可预注册）：当 `实现波动率 < 扩张窗口 50% 分位` 且 `回撤未继续扩大`，则每 N 个交易日恢复一档 gross。**规则必须在实验前写死，不能事后调参。**
4. A/B 设计：控制组 = 现阶梯；处理组 = 波动率触发 + 对称再风险。**只改这一个变量**，其余配置、数据、种子全部冻结。

**判据**：处理组 CAGR 提升必须超出引擎噪声带（§3.1），且 MaxDD 恶化 ≤ 2pp。若 CAGR 无提升，说明阶梯不是瓶颈，**该假设被证伪并记录**。

### P1-4 协方差估计升级

**问题**：`allocation.py:25` 用 `LedoitWolf().covariance_`。LW 向**对角矩阵**收缩，在 20 只票、120 天窗口下会系统性**低估共同因子风险**（因为它压制了非对角项）。结果是：目标波动 14% 的约束在 regime 切换时失效，实际波动与回撤超出预算。

**做法**：
1. 用 §2.1 的因子模型做收缩目标：`Σ = B Σ_F B' + D`，再与 LW 混合
2. 叠加 EWMA 市场波动标量：`σ_forecast = max(Σ 模型隐含波动, EWMA(60) 市场波动 × 组合 β)`
3. 波动率预测**取保守值**（取大不取小），因为回撤预算是硬约束

**落点**：新增 `quantlab/risk/covariance.py`；`allocation.py` 的 `cov=` 换源。

**判据**：比较"目标 14% 波动"下的**实现**波动与**实现** MaxDD。若实现 MaxDD > 2 × 年化波动（经验上权益策略在 1.5–2.5× 区间），说明协方差低估；把 `target_vol` 下调到让 `1.8 × target_vol ≈ 22%`（即约 **12%**）再看。**注意：mandate 里 `target_vol=0.14` 与 `drawdown_halt=0.20` 在数学上不自洽**——14% 波动的一年期 1.4σ 事件就是 −20%，而权益类最大回撤的经验倍数是 1.5–2.5 倍年化波动（21%–35%）。**要么把 target_vol 降到 ~11%，要么承认阶梯会被触发。**

## 4. 信号层：什么条件下才值得做

**数学前提**：`IR = IC × √BR`，`BR ≤ 23` → `IR ≤ 4.8 × IC`。IC 从 0.10 提到 0.15（这已经是公开因子难以达到的水平），IR 只从 0.48 提到 0.72。

**值得做的四个条件（必须同时满足）**：
1. **低换手**：月频或更低（你的 `rebalance_rule="weekly"` + `min_holding_period_days=20` 已经偏保守，不要再提频率）
2. **经济逻辑可写清**：能写成预注册假设（"为什么这个信号应该赚钱、在什么条件下失效"）
3. **与现有因子低相关**：现有 11 个因子（momentum×4、value×3、vol×1、flow×2、crowding×1）+ 5 个专家里 3 个是动量类——**动量方向已经过度拥挤，不要再加**
4. **容量不设限**：60 万不受限，但规则要为未来规模留余地

**优先候选（按预期价值排序）**：
1. **质量**（ROE 稳定性、毛利率、低杠杆）— 容量大、衰减慢、A 股实证有效
2. **真实价值**（EP/BP/FCF，PIT 财务）— 取代当前的 `−ret250` 伪价值
3. **PEAD（盈余惊喜漂移）**— A 股散户反应不足，`factor_growth(sue)` 已有代码但缺数据
4. **分析师预期修正**（需新数据源，成本高，暂缓）

**明确不建议**：再加动量变体、再加专家（现有 5 个已足够）、任何日内/高频方向（监管口径 + 60 万规模都不支持）。

## 5. 三条路线的技术含义（这是决策，不是研究）

| 路线 | 技术含义 | 需要什么 | 预期结果 |
|---|---|---|---|
| **A. 放宽宽度** | BR 从 23 → 300–500，IR 从 0.48 → 1.7–2.2 | **必须改 mandate**（`target_positions` 上限、单票 6% 权重） | 超额可到 15%+，但个股集中度下降、跟踪误差上升 |
| **B. 显式 beta 承载**（推荐） | 承认 15% 里大部分来自 β，把 α 层目标降为"风险调整后微调"；重点补归因、协方差、再风险规则 | 不需要改 mandate，不需要新数据 | CAGR 变化不大，但**归因清晰、回撤可控、不再自欺** |
| **C. 下调目标** | 目标从"年化 15%"改为"跑赢自建池基准 + 回撤 ≤ 20%" | 只需改判据 | 目标可达，但放弃 15% 的绝对值诉求 |

**三者不互斥。** 我建议的顺序是 **B → 再决定 A 或 C**。理由：不先把 β/α 分离，你无法判断"放宽宽度"能拿到什么；而现在所有"超额"数字都被 size beta 污染了。

```
第 6 步  （可选）低相关基本面因子接入组合          → strategy/experts.py               依赖第 5 步
```

**第 0–4 步全部不需要新数据、不需要新因子，全部可以用现有冻结数据与账本做。** 第 5 步是唯一需要补数据的。

**每一步的产出都是"是/否 + 数字 + 台账一行"，不是"更好的曲线"。**

## 8. 一句话总结

**你的问题不是"因子不够好"，是"收益没被拆开、风险层锁死了复利、而基本面这条路根本没通"。** 前两件事用现有数据和代码就能查清，第三件只需补一个字段。在这三件事做完之前，任何新的因子、模型或"更聪明的策略"都不会改变结果——因为它们作用在一个被错误测量的目标上。
