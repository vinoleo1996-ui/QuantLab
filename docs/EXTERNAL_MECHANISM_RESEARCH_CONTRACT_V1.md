# 外部机制接入研究契约 V1

状态：已落地研究侧车和失效关闭接口；**尚未启动新账户、未改冻结路由器、未自动交易**。D2
仍须按既有预注册归档和判决，才可能登记任何后续账户实验。

## 目的和边界

四个外部项目提供的是候选机制，不是现成收益证明。本契约把它们拆成可以证伪的输入、信号、
评分和评估层，并禁止借用本仓已测失败结果否定外部算法，也禁止把外部演示结果写成当前账户
收益。所有新实现均为独立代码，不复制 easy-stock 或 MiroFish 源码。

新增实现位于：

- `quantlab/research_signal_ledger.py`：追加式原始信息、实体/题材、特征/弃权、结算结果账本。
- `quantlab/research_universe.py`：U0/U1/U_broad 与 20-session 节奏的独立池子契约。
- `quantlab/theme_carrier.py`：`theme_carrier_minimal_v1` 四分量等权、仅新入场排序。
- `quantlab/theme_carrier_graph.py`：独立的 `theme_carrier_graph_v1` 多对多题材图谱；保留所有
  原生边、获胜题材、边数与回执哈希，不能改写或替代已归档的 minimal V1。
- `quantlab/forward_market_capture.py`：仅接收单一、已声明来源的原始盘后分页 bytes，逐页写回执，
  再从连续前向快照派生 U0 与题材账本观察。
- `quantlab/data/provider_trial.py`：三个供应链的合同、自动访问/原始留存许可、能力与小样本回执
  验收；不发网络请求，也不把任何未验来源接入题材、文本或 L2。
- `quantlab/forward_h5_evaluation.py`：仅信息检验的 T+1 开盘至 T+6 开盘标签与固定五-session
  非重叠报告块；没有账户、年化、仓位或订单接口。
- `quantlab/data/l2_contract.py`：L2 试用验收、可执行标签、embargo 与 score-only 产物。
- `quantlab/external_research_controls.py`：文本、多代理、K=8 仿真、主线矩阵、融合/结构门禁。

这些模块均不导入账户执行入口作为副作用。D2 归档门只可提供**研究登记证据**，绝不授予账户
执行权；当前没有外部机制账户适配器。任何未来账户调用还须经单独预注册、用户授权和独立
执行适配器，不能由本侧车的登记结果触发。

## 信息账本和题材首测

账本为 SQLite 哈希链，并保存原始 bytes 的 SHA-256 blob。它记录四类业务对象：

1. 原始回执：来源/原始发布者、内容哈希、`published_at`、`first_captured_at`、`available_at` 与真实
   `written_at`；晚到、失败和部分成功同样留证，不能因不适用于某一决策而丢弃。
2. 实体和题材映射：映射规则、模型/提示词版本及不确定原因。
3. 特征或显式弃权：18:00 决策截点前可用的证据、覆盖率与原因。
4. 结算结果：标签终点和结算可用时点；未结算记录不能反馈给后续研究。

晚到、无来源、转载重复、内容哈希失配、实体/题材不确定、缺失分量均对**指定决策**显式弃权，
绝不以 0 代替。晚到不是全局丢弃：原始回执照常保存，只能在下一次符合其 `available_at` 的资格
检查中使用。文本共识至少需要两家独立、非转载原始来源。

### 前向市场采集的已实现边界

当前采集侧车是**原始证据接收器，不是已启用的日常数据服务**。此前冻结的 Eastmoney profile
只保留为时钟/完整性回归夹具；它没有通过本计划所需的自动访问和原始留存授权，**不得作为新
题材、文本、U0 或 H=5 的生产性来源**。新的薄路径只能由一份通过
`provider_trial` 的供应商专用实现接入，不能把新浪/腾讯回退、本地缓存、解析后 DataFrame 或
其他 URL 伪装成同一来源。整页缺失、页总数不一致、来源 profile 不符、解析失败、重复证券会使
对应截面显式弃权，不能形成池或排序。15:30--17:50 是该日收盘截面**原始页捕获**申请进入
18:00 决策的资格窗，不是采集停机线；全套页在窗内捕获后，即使验证在 17:55 后、只要实际写入
不晚于 18:00，仍可形成该次池/排序。题材、公告和文本不套用这条 17:50 规则，它们按自身
`available_at` 和该次决策时点判定。窗外市场页仍会带真实时点入账，只是不能形成或改写该次池/排序。

每一页的原始 bytes 会单独写入账本；若供应商不提供可核验发布时间，`published_at` 与
`available_at` 诚实取 HTTPS 首次捕获时点并标记该依据。通过验收的行情源可以提供最近 **253** 个
交易日的日线种子，仅用于在上线当天构造当前 U0 的 60 日 ADV 与此前 252 个价格日资格；该种子
不得回填历史题材信号、文本、H=5 标签或账户收益。之后每个新决策日仍只使用其真实前向回执。
图谱题材 V1 需要前一日/当日完整 bars、来源原生多对多边和所有 canonical 回执；缺任一对象时已声明
scope 写全范围弃权，基准新入场顺序不变。

尚未有网络 transport、调度器或已验的原始题材映射来源，故尚未发生真实日常采集，也没有账户实验。
启用前须另冻结请求 manifest（参数、页数、收盘时钟、失败规则）及题材映射来源；换源属于新版本，
重新累计覆盖。

题材行中的 `source_receipt_id` 和 `content_sha256` 不是可由 DataFrame 自报的字段：每一条被评分的
行必须回验为账本中 canonical、accepted 的回执。对于一个明确的 18:00 决策，原始 blob SHA-256、
发布/首次采集/可用/实际记账时点均须不晚于该截点；否则只对该次决策弃权，回执仍保留给未来。
账本哈希链或任一回执不一致时整期弃权。实体映射也必须来自本次已提交的 canonical 回执，并精确
覆盖被观察的目标实体，不能把无关来源或 A 的映射拼接给 B。

`theme_carrier_minimal_v1` 的唯一主终点是下列四项方向校正后的跨题材百分位的算术平均：

1. 昨日涨停溢价；
2. 炸板率（负向）；
3. 题材相对强弱；
4. 上涨广度。

竞价、资金扩散、情绪空仓、龙头、文本、墙钟新鲜度均不在 V1 schema 中。任一数据来源或
U0 映射缺失时，本期整体弃权并返回基准排序逐字节不变。题材得分只能重排新入场，持仓保留、
费用、风险、权重、调仓时钟和执行日期保持固定。四个分量只输出诊断，不能在同段历史中择优
晋级。

`theme_carrier_minimal_v1` 保持历史归档，不删除也不改口径。新的
`theme_carrier_graph_v1` 是独立实验：输入为来源原生的股票—多题材边；题材端仍只算上述四项等权，
股票端固定取全部**合格**题材分数的最大值。同一来源明确确认但没有合格题材的股票记为 `0`；
来源缺失、映射部分覆盖、混合状态、重复边或实体不确定则整期弃权。输出必须同时带出完整原生边、
每股获胜题材、全部/合格边数、原始回执 ID 与内容哈希；同分只按既有基准候选顺序，不改变保留持仓、
风险、费用或调仓节奏。

## 多代理和仿真

多代理简报仅允许输出事实、引用、催化剂、失效条件、分歧或弃权；只能覆盖冻结池内股票，不能
给 Buy/Sell/评级/仓位，也不能使用未结算的结果反馈。嵌套结构同样禁止交易字段；每个引用必须
由 `ResearchSignalLedger` 实时回验为 canonical、及时的账本回执，并记录模型和提示词 SHA-256，
不能用手写的 `status/raw_sha256` 映射代替。MiroFish 风格仿真必须先由账本 coverage 生成包含
scope、成员、journal hash 的覆盖快照和预先登记门槛；随后固定 K=8、8 个唯一 run/seed，以实际
动作日志重新计算并核验 SHA-256，只从该日志计算传播范围、动作密度、集中度及运行间 IQR。
`stance` 与 `sentiment_bias` 是运行时未消费参数，明确拒绝进入输入或因子。

## L2 契约

L2 不读取当前快照来训练。试用数据先通过 provider/trial/source release、原始响应 hash、字段
字典、单位、缺失规则与每一字段 `available_at` 验收。14 个已冻结键都必须出现，任一项缺失、
重复、晚到或版本/hash 不一致即弃权，不训练。

固定键为 `micro_vpin_vol_ratio`、`micro_vpin_amount_ratio`、`micro_pin`、
`micro_zone_distribution`、`micro_zone_vol_ratio_T4`、`micro_zone_vol_ratio_T6`、
`micro_zone_vol_ratio_T5`、`micro_zone_vol_ratio_T3`、`micro_zone_rv_ratio_close`、
`vol_price_divergence`、`micro_open_gap`、`micro_impact_decay_half_life`、
`micro_liquidity_daily_pattern`、`flow_imbalance_revert_speed`。键名来自审计过的外部目录；单位、
原始字段、版本和缺失规则不由本仓猜测，必须由每次试用 manifest 显式声明，且缺失规则只能是
`abstain`。

H=5 只产生无账户的信息标签：T 日 18:00 决策，T+1 开盘入场、T+6 开盘退出；标签的可用时点是
退出开盘数据和 T+6 18:00 中较晚者。训练/验证按每条真实标签可用时点 purge，且 H=5 的
embargo 固定为 6 个 session。20 日账户需要独立 H=20 契约、标签和 embargo，不能复用 H=5。
`source_as_of` 不得晚于字段 `available_at`，训练标签不得晚于 `training_as_of`；开盘许可假设和
许可适配器身份均进入标签契约哈希。

CatBoost（未来单独授权）只允许产出 `score` 和 rank 的 `predictions.parquet`，并且每一行及整份
文件必须绑定通过验收的 L2 物化特征矩阵身份。`position_score`、
`fusion_score`（包括 `quality.position.position_score` 等大小写/命名空间变体）、TopkDropout、`p^3`、
半凯利、止损和自动换模型不属于该文件，不能混入 L2 首测。

### H=5 前向信息结算

每日已冻结的题材图谱分数在到达 T+6 后只生成截面 Spearman RankIC 与原始开盘到开盘价格标签；
它不是持仓、净值、交易成本或年化收益。每个入场/退出开盘必须来自各自交易日已写入的原始回执，
不能在 T+6 补抓 T+1 的历史页。报告块由上线时冻结的完整交易日历与锚点决定：每五个交易日一块，
相邻块只在前一块退出与后一块入场时相接，不能在看结果后改锚点或挑窗口。缺页、晚到、回执哈希
失配或无法计算 RankIC 都追加为 `unavailable`，绝不写成 0。

连续 3 个完整采集日及 3 个完整题材端点日只说明链路可用；至少 20 个已结算、非重叠 H=5 报告块才
满足后续账户实验的样本量前提。它仍额外需要 D2-v2 完整归档、预注册和用户单独授权；
`account_execution_authorized=false`。

## 评估、融合和披露

D2 `archived_decided` 只允许**登记**一个后续研究 A/B，绝不启动账户；其 v2 预检必须在完整交易
日历上重构 0/4/8/12/16 相位，每一相位以 `(-financial_score, liquidity_rank)` 重新选名单，保留尾部
溢出，并拒绝旧代码/输入顺序的 phase-0 哈希或任意重复的非零相位哈希。其裁决 manifest 与完整
十格归档身份须由 SHA-256 绑定 `pre_registered_full_matrix` 选择依据，不能以最高单格年化替代。
两臂必须固定池、
费用、持仓、风险、保留、节奏和执行，只变新入场排序；池定义、成员、候选集、保留持仓、费用、
风险、执行、代码和数据身份均需分别冻结为 SHA-256。首测 treatment 必须是实际的
`ThemeCarrierEntryArtifact`：冻结 U0 成员、四项等权结果、账本/回执身份，以及仅新入场排序；不能
用任意 sorter 字符串注册。U1 必须同时携带同一决策日、同机制的 U1 artifact 和已验 U0 source
artifact，标为复制臂并另绑复制协议，不能因已看历史较高就取代 U0。融合只有各单专家已有预注册
净增量后才可登记；5/10 日或 40+10、30+20 等持仓结构实验也要等信号固定后单独比较。

主线必须披露五相位 `0/4/8/12/16` × `base/double` 成本的全部十格、中位扣费年化、最差相位和
每格回撤；回撤无论以正损失幅度还是负值报告，绝对幅度任一格大于 25% 即不进入主线。35% 探索账
与最高单格年化均不得作为选择规则。
每份结果必须保留完整搜索家族、失败结果、覆盖率、代码/数据/模型身份和明确的决策影响，且
`promotion_approved=false` 直到既有数据、执行和前向门槛全部通过。
