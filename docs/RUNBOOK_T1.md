# T+1 半自动落地 Runbook（v1，2026-10-17）

## 一、流程（P5_BASE）

1. **股票调仓日**（每 20 个交易日，相位 0）收盘后：
   ```
   .venv/bin/python scripts/p5_base_orders.py --signal-date <YYYY-MM-DD> [--cash <当前现金>]
   ```
   产出 `output/p5_base_orders/<signal-date>/orders.csv` 与 `summary.json`。
2. **次日开盘前**：核对 `summary.json`——拒单原因、现金缺口、QDII 是否暂停、覆盖率。
3. **开盘**：按 orders.csv 在券商下单（v1 为人工下单，记录实际成交价与数量）。
4. **收盘后**：`scripts/reconcile.py --orders <orders.csv> --fills <成交.csv>`：成交价 vs `limit`、实际滑点 vs 30bp/5bp 假设、未成交单、剩余现金、持仓偏离。
5. **季末**：ETF 袖按 3:3:2 再平衡（黄金 518880 / 十年国债 511260 / 纳指 513100）；QDII 溢价 >3% 暂停，溢出权重 1:1 分给黄金与十年国债（本版已实现）。
