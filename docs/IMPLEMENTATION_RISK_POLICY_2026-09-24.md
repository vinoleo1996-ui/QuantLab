# 动态风险政策实施记录

## 本轮实现

- `legacy_repaired`保留原专家公式与月度选股；P0、P1、P2经Mandate、配权、订单、开盘成交、每日风险和报告贯通。
- P1/P2使用12/18/22/25%回撤档位，取消相对等权上界，新增软硬缓冲；目标波动按实际风险缩放，消除重复固定减仓。
- 现金自然漂移的确定性反例已修复：现金比重只缺0.0168个百分点时不再逐股卖出1,400股。每笔买入仍预留现金和费用。
- 执行延迟保存信号日目标股数，最早执行交易日随订单记录；25%退出、部分未成交、人工恢复及前向追加行情均有行为测试。
- 质量/PB、财务覆盖对照、行业轮动、同名单等权为独立候选；8个主配置+2个参考名额，不做全排列。
- 每周观察、每月换仓、每日风险共用决策。纸面账户支持legacy与风险政策身份，不要求Forecast；日志不能冒充冻结前向证据。
- 逐字段只读本地适配器，免费补采真实换手/ST/停牌、除权参考价及分红支付日期。原始响应和导出目录按哈希保留。
- 主期间2020—2026H1；三段主检验与2026H1分开，20/60日家族分块、实际矩DSR、成本和命中退出的压力测试已接入。
